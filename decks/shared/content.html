How it works

One install. The whole chain, instrumented.

STEP 1 · MONITOR
Drop in the agent
One MCP config or GitHub Action. No code changes, no rip-and-replace.
STEP 2 · INSPECT
Inspect every build
Chalk records a deterministic SBOM + provenance inside the build itself.
STEP 3 · TAG
Tag the artifact
A tamper-proof fingerprint is embedded into the image that ships.
STEP 4 · TRACK
Track in production
Artifacts beacon back — query your live fleet from your coding agent.

Accessibility: WCAG 2.2 Level AA: all brand surfaces

Conformance statement

Every Crash Override brand surface targets WCAG 2.2 Level AA (SC 1.4.3 Contrast Minimum for normal and large text; SC 1.4.11 Non-Text Contrast for interactive and graphical elements; SC 1.4.4 Resize Text; SC 2.4.7 Focus Visible). AA is the floor, not an aspirational goal. Every semantic role pair in every published theme variant must clear it before merging.

CI enforcement: contrast is checked by scripts/check-contrast.mjs against the role pairs declared in scripts/contrast-pairs.json on every pull request. A failing pair blocks merge. AA-aware token values such as --color-fandango-700 (#5A2173) are asserted facts baked into the token source, not advisory comments.

Focus visible

All interactive elements must have a visible focus indicator at 3:1 contrast against adjacent colors (SC 2.4.11 Focus Appearance, targeting AA). The design system uses Atomic lime (#B3FF00) as the focus ring color on dark surfaces and Fandango-700 (#5A2173) on light surfaces. Do not suppress :focus-visible outlines without providing a custom replacement that meets the ratio.

Authoring guidance

Always: Use semantic role tokens (--text-primary, --text-secondary, --surface-primary) rather than raw palette values when styling text and surfaces. The semantic layer is designed to pass AA in every supported theme variant; raw palette values may not.

Never: Place Atomic lime text or filled elements on white or Thunder-100 (#F7F5F2) surfaces. The contrast is insufficient for any WCAG level. Swap to --color-fandango-700 for light-mode actions.

Deck and marketing artifacts: Apply the same role-pair rules. Use --text-primary on --surface-primary (Black) for body copy on dark slides; use Fandango-700 on fandango-100 tint blocks for callouts on light slides. Provide alt text on all non-decorative images; see the skill reference references/accessibility.md for alt-text guidance.
